# SomaAtlas assets on the ClinicalCode project page

Catalog source: https://somaatlas.org/ (retrieved 6 October 2026).
The interactive previews load the original public SomaAtlas GLB URLs on demand.
Downloads link to SomaAtlas, preserving its asset kits and associated notices.
The CT and MRI entries select named nodes from their corresponding shared GLB
collections; each node is a label surface, not a separate participant.

ClinicalCode adaptation: selected and framed the existing 3D geometry, then
rendered transparent WebP thumbnails on a white page. No anatomical geometry,
label, texture, or simulation result was invented or edited. The atlas preview
meshes and appearance maps retain the upstream modifications described in
atlas-preview.txt. These renderings inherit the applicable source terms.

CC-BY-SA 2.1 Japan; Z-Anatomy — The libre 3D atlas of anatomy — CC-BY-SA 4.0.
See Z-Anatomy-License.txt and atlas-source.txt for full source notices and
exceptions. Liver and gallbladder photograph credits and generated appearance
map attribution are retained in atlas-preview.txt and atlas-source.txt.

automatic TotalSegmentator labels; modified by LifeCode and SomaAtlas.
Full source license: CT-LICENSE.txt.

Contact model: https://somaatlas.org/data/physics/README.md
The model thumbnail shows reference geometry; the numerical replay is linked
separately. The catalog does not imply clinical validation or calibrated physics
for the other anatomical meshes.
