# TACE atlas example

The reference anatomy and animation are adapted from TACE Anatomy Atlas v7. The original catheter, syringe, particle transport, and model-time mapping are retained. The reference atlas is not registered to the adjacent CT example. Vascular transport is illustrative; the animation does not model drug dose, chemotherapy response, or patient outcome.

This edition removes baked interface text and borders and presents synchronized anatomy and liver crops with responsive HTML labels. The time axis compresses the original model timeline into a 12-second animation.

Anatomical geometry: Z-Anatomy / BodyParts3D. Z-Anatomy contributors, Gauthier Kervyn, and BodyParts3D / Database Center for Life Science (original model: Kousaku Okubo).
